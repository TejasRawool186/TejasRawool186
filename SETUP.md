# Profile README Setup

1. Ensure your public profile repository is named exactly `tejasrawool186`.
2. Copy `README.md`, `assets/`, `scripts/`, and `.github/workflows/` into your repository root.
3. Commit and push to `main`.
4. Open **Actions → Update Contribution City → Run workflow** (or let it run automatically daily at midnight).
5. The workflow refreshes `assets/city.svg` with your latest live contribution history automatically.
